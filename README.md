## Overview / 项目简介

基于 **Google Antigravity /swarm** 构建的全自动化科研作图多智能体系统，专注于顶刊/顶会论文 **全览大图（System Overview / Pipeline Figure / Graphical Abstract）** 的结构拆解、视觉生成与出版级审美校对。

> **Status**: Repository initialized and open-sourced under MIT. Architecture design and multi-agent /swarm implementation in progress.
